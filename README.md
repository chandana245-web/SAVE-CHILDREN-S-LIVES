# Save Children's Lives

Save Children’s Lives is a Flask prototype for a pediatric medical crowdfunding and verification platform.

## Features

- Login-first landing page with role-specific access
- Demo authentication for Patient / Guardian, Donor, Hospital, and Admin
- Campaign discovery and donation demo flow
- Multi-step fundraiser application with document upload interface
- AI verification demo workflow and hospital/admin review screens
- Responsive, healthcare-themed interface using Flask, Jinja2, CSS and JavaScript

## Run locally

1. Open the project folder in VS Code.
2. Create a Python virtual environment if desired.
3. Install dependencies:
   `pip install Flask python-dotenv Pillow`
4. Start the app:
   `python app.py`
5. Open:
   `http://127.0.0.1:5000`

## Demo accounts

- Admin: admin@demo.local / Admin@123
- Patient: patient@demo.local / Patient@123
- Donor: donor@demo.local / Donor@123
- Hospital: hospital@demo.local / Hospital@123

## Notes

This project is a prototype and uses DEMO DATA only. It does not process real payments or real medical records.
